# AventIQ V1
Self-contained Next.js project prepared from the AventIQ code/data supplied in this conversation.

## Run
npm install
npm run dev

Then open http://localhost:3000.

## Important
The supplied source contained 27 opportunity records, but only excerpts of the full dataset were accessible in the conversation. Records whose complete source details were not available here are marked as AventIQ Research Database entries and should be verified before public launch. Verify all deadlines, eligibility, status and URLs against official sources.
